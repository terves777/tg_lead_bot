# 🚀 Telegram Lead Generation Bot (NovaLead)

Асинхронный Telegram-бот для автоматизированного сбора лидов и клиентских заявок. Проект реализует пошаговую воронку сбора контактных данных и мгновенно перенаправляет структурированную карточку заказа администратору, параллельно сохраняя информацию в локальную базу данных.

---

## 🛠 Стек технологий

- **Язык:** Python 3.14+
- **Фреймворк:** [aiogram 3.x](https://docs.aiogram.dev/) (полная асинхронность, FSM)
- **База данных:** SQLite3 (хранение лидов с метками времени)
- **Конфигурация:** python-dotenv (безопасное хранение токенов)
- **Сетевой уровень:** aiohttp, aiohttp-socks (поддержка проксирования трафика SOCKS5/HTTP)

---

## ⚙️ Основной функционал

1. **Многошаговый FSM-диалог:**
   - Последовательный опрос пользователя (имя $\rightarrow$ номер телефона $\rightarrow$ описание задачи).
   - Изоляция состояний каждого пользователя без взаимных блокировок.
2. **Мгновенное уведомление администратора:**
   - Формирование аккуратной HTML-карточки со всеми данными клиента и прямой ссылкой на его Telegram-профиль.
3. **Персистентное хранение (SQLite):**
   - Автоматическая инициализация таблицы при запуске.
   - Запись всех обращений в файл базы данных `leads.db`.
4. **Сетевая устойчивость:**
   - Настроенная поддержка локального SOCKS5-шлюза для стабильной работы API в условиях сетевых ограничений.
